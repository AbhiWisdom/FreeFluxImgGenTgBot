## ✨ Features

- 🖼️ **AI Image Generation** — Generate stunning images from text prompts
- ⚡ **Flux Models** — Powered by state-of-the-art Flux image generation
- 🆓 **Completely Free** — No API keys or payments required for users
- 🤖 **Telegram Integration** — Simple /generate command interface
- 📏 **Multiple Sizes** — Support for various image dimensions
- 🔄 **Queue System** — Handles multiple requests efficiently

## 🚀 Quick Start

1. Clone the repository
```bash
git clone https://github.com/AbhiWisdom/FreeFluxImgGenTgBot.git
cd FreeFluxImgGenTgBot
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Set up environment variables
```bash
cp .env.example .env
# Edit .env with your Telegram Bot Token
```

4. Run the bot
```bash
python main.py
```

## 🛠️ Tech Stack

- **Language:** Python 3.9+
- **Bot Framework:** python-telegram-bot
- **Image Generation:** Flux AI Models
- **Hosting:** Any VPS or cloud platform

## 📝 Commands

| Command | Description |
|---------|-------------|
| `/start` | Start the bot |
| `/generate <prompt>` | Generate an image from text |
| `/help` | Show help message |
